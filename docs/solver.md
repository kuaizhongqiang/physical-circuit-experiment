## 1 先说清楚"以前为什么会错"

换语言救不了这五条，它们必须在算法层显式处理（D-20261103-11）。任一缺失，结果就会"看起来对但不对"：

| # | 根因 | 本文件的对策 |
|---|---|---|
| 1 | 等势点合并后索引映射错位（合并了节点，支路仍指旧号） | §3：合并与编号**一次成对完成**，支路只存等势点索引，不存接点索引 |
| 2 | 开关器件迭代不收敛 / 触点抖动 | §6：状态向量不动点迭代 ＋ 滞环 ＋ 振荡检测 |
| 3 | 三相单位与复数混用（线/相电压、√3、弧度/度） | §8：相位内部一律弧度、对外一律度；线/相电压只在 `POWER` 一处换算；量纲用 newtype |
| 4 | 拓扑变更后矩阵未重排 | §2：每次 `solve` 全量重建，**没有增量复用**（10 类电路的规模不值得为增量优化冒错位的风险） |
| 5 | 奇异矩阵无处理（缺参考点 / 孤岛 / 开路） | §4 参考点强制、§5 极大电阻替代开路、§9 残差校验 |

## 2 建模范式（一期）

- **相量稳态**：所有电压电流为 `RMS 幅值 ＋ 相角`，频率由 `POWER.freq` 给定（D-20261103-03）。
- **改进节点法（MNA）**：未知量 = 非参考等势点电压 ＋ 每个电压源支路电流。电压源用标准增广行列，不用"大电导近似"。
- **每次调用全量重建矩阵**：接点 → 等势点 → 支路 → 矩阵，全流程一次做完；无缓存、无增量。这是为根因 4 付的保险费。
- **稠密 LU ＋ 部分主元**，接点数上限 1024，实际 10 类电路远小于此（`architecture.md` §5）。

## 3 等势点合并与编号（根因 1）

```
1. 接点编号：按器件数组顺序 × 器件接点顺序 → 0..N-1（稳定、可预测）
2. 并查集：对 wires 每条 {a,b} 做 union；对每个 TB 内部接点做 union
3. 取根 → 按"组内最小接点 id"升序重排 → 等势点索引 0..M-1
4. 支路展开时立即把两端接点替换成等势点索引，之后不再出现接点索引
```

- 第 3 步的**按最小接点 id 排序**是确定性要求的落点：不同运行、不同哈希种子必须得到同一套编号（`AGENT.md` §2）。
- **闭合触点不参与合并**：它有 `r_contact`，必须留在矩阵里（`domain-model.md` §3）。

## 4 参考点与连通分量（根因 5）

- 在"等势点图"上（边 = 器件支路，含开路支路）求连通分量，然后**按有无电压源分成三类**（D-20261103-25）：

| 类 | 判据 | 处理 |
|---|---|---|
| **有源分量** | 含 `POWER` 的电压源支路 | 必须恰含一个 `PE`，参与求解 |
| **无源孤立分量** | 有支路但无电压源（如删光导线后孤零零的一个绕组、一组触点） | **不参与求解**：相量稳态下无源网络电流必为 0，其接点电压按 `0 V` 输出并标 `FLOATING`（`api.md` §2.5 `flags` bit2） |
| **单接点分量** | 连一条支路都没有（如没接线的接点） | 同"无源孤立"，`0 V` ＋ `FLOATING` |

- **为什么无源分量可以直接忽略而不是报错**：这不是兜底，是数学上精确的。一期是相量稳态、无储能初值，无源网络的稳态电流**必然**为 0，求解它只会得到全零 —— 跳过它不改变任何结果，只省掉一次奇异矩阵。这一条**没有开关**，任何模式下都这么处理。
- **有源分量仍强制参考点**（D-20261103-21 取 A）：电位是相对的，没有参考点的"电压"没有物理意义；教学场景里"忘了接地"本身就是接线错误，静默兜底会把错误教成正确。一个分量里两个 `PE` → `E_MULTI_REFERENCE`。
- **两档严格度**（`api.md` `pcx_input_t.flags` 的 bit0）：

| 模式 | `STRICT_REFERENCE` | 有源分量缺 `PE` 时 |
|---|---|---|
| **严格**（默认，`fixtures/` 与 Unity 样例走这档） | 置位 | `E_NO_REFERENCE`，诊断带上该分量的等势点列表 |
| **宽松**（演示页编辑中间态） | 清零 | 取**该分量内 `POWER.N` 为隐含参考**，返回成功，附 `W_IMPLICIT_REFERENCE` 警告 |

- 宽松模式的存在理由：演示页允许"把导线全部删光再逐条重接"（`demo.md` §7），中间态必然没有完整参考；此时要求页面每个接点仍有正确数据，就必须能算。**正式网表永远走严格模式**，"忘了接地照样报错"这个教学价值一点没丢。
- **孤岛判定收口**：`PE` 单独一个分量（没接线）→ 属"单接点分量"，忽略；`PE` 与 `POWER.N` 同分量 → 该分量参考点就是 `PE`，正常。

## 5 数值常量表

**这是全工程唯一的数值口径来源**。`domain-model.md` §4 管器件参数，本表管数值假设。代码里 `core::consts` 逐项对应，编号 `N-01…`。

| 编号 | 项 | 值 | 依据 |
|---|---|---|---|
| `N-01` | 数值类型 | `f64` | Rust / C# / JS 三端同为 IEEE-754 binary64（D-20261103-13） |
| `N-02` | 触点 / 端子接触电阻 | `1e-3 Ω` | 真实 mΩ 级；让导通电流保持可读量级 |
| `N-03` | 断开状态等效电阻（含"空气电阻"） | `1e9 Ω` | 380 V 下漏电 `3.8e-7 A`，与 `N-04` 差 2600 倍，判定无歧义 |
| `N-04` | 开路判定阈值 | 支路 `I < 1 mA` | 高于漏电量级一个数量级以上 |
| `N-05` | 过流告警阈值 | 支路 `I > 50 A` | 电机启动电流（6~8 倍额定）之上 |
| `N-06` | 短路判定 | 见 §7（拓扑规则） | 不靠电流阈值 |
| `N-07` | 线性求解残差上限 | `‖Ax−b‖/‖b‖ ≤ 1e-10` | 远小于断言容差 1% |
| `N-08` | 主元阈值（判奇异） | `|pivot| < 1e-14 × max|A|` | 低于即视为奇异 → `E_SINGULAR_MATRIX` |
| `N-09` | 开关迭代表 | 状态向量不变即收敛，上限 `100` 轮 | 超限 → `E_OSCILLATION` |
| `N-10` | 默认电压 / 频率 | `380 V` / `50 Hz` | 常考点，可被 `POWER` 参数覆盖 |
| `N-11` | 相序 | 正序 `L1 → L2 → L3`（`0° / -120° / +120°`） | 默认正序，参数可改负序 |
| `N-12` | 相位单位 | 内部弧度，**对外一律度** | 防"弧度当度"（根因 3） |

**三层覆盖机制**（后者优先）：`consts` 缺省 → `POWER` 器件自带参数 → 网表全局 `SolverConfig`。

## 6 开关迭代（根因 2）

```
state₀ = 应用给定的 QS/SB/SQ 状态 ＋ (应用给的 closed 提示位，若有) ＋ 其余触点全断开
loop (≤ 100):
    装配 MNA（按当前 state 决定每条触点是 r_contact 还是 r_open）
    LU 求解 → 各线圈电流 |I_coil|
    新状态 = 对每台 KM/KA：
        当前吸合 → |I| ≤ drop_current 才释放（滞环下界）
        当前释放 → |I| ≥ pick_current  才吸合（滞环上界）
     对 KT / FR / KS：按应用传入的 elapsed_ms / rpm 与阈值比较
    若 新状态 == state → 收敛，退出
    记录 state 到已访问集合；若新状态曾出现过 → 判定振荡
    state = 新状态
```

- **滞环是必需的**，不是优化：没有滞环，线圈电流落在 `pick` 附近时状态会逐轮翻转，永远不收敛。`drop_current ≈ 0.6 × pick_current`（`domain-model.md` §4）。
- **滞环需要上一轮状态**：默认从"全断开"起步可能落在错误分支（线圈电流恰好介于 drop 与 pick 之间时）。因此允许应用把上一次的触点状态作为**提示**传入；不传也能算，但结果可能与连续仿真有偏差。这是无状态设计的已知代价，写进 `api.md` §3 的调用约定。
- **振荡处理**：检测到状态循环 → 先做一次"优先上一轮状态"的仲裁重试；仍振荡 → `E_OSCILLATION`，附上循环的状态序列（诊断里给出参与振荡的器件 id 列表），**绝不静默返回半吸合结果**。

## 7 短路判定（`N-06`，拓扑规则，D-20261103-22）

导线是理想连接，电源两极若被导线直接连通，等势点相同、矩阵奇异 —— 所以短路必须在装配之前做**拓扑预检**，而不是靠求解出的巨大电流去发现。

**规则**：在"等势点图"上，若 `POWER` 的任意两个不同相（或任一相与 `N`）之间存在一条通路，其全部器件都属于**导体类**，则判 `E_SHORT_CIRCUIT`。

| 类 | 器件 |
|---|---|
| **导体类**（不阻断短路） | 导线、`QS`、`FU`、`FR` 热元件（`1-2`/`3-4`/`5-6`）、`TB`、各类**闭合**触点（`KM`/`KA`/`KT`/`KS`/`SB`/`SQ`/`FR` 辅助） |
| **负载类**（阻断短路） | `M` 绕组、`R`、`EL`、所有**线圈**（`A1-A2`）、`POWER` 自身 |

- 判定发生在**迭代过程中每一轮**（触点状态在变）：星三角切换若两个接触器同时吸合，会在这里被抓住 —— 这正是 C5 案例要断言的"互锁有效性"。
- 诊断携带：短路的两个相、路径上的器件 id 列表。

## 8 三相与相量口径（根因 3）

- `POWER` 内部生成 3 条电压源支路，幅值 `v_line/√3`，相角按相序 `0° / -120° / +120°`；**线/相电压换算只发生在这一个地方**。
- 线电压 `= √3 × 相电压`，相位超前对应相电压 `30°`；**不给调用方自动换算**，需要线电压就两点相减（`D-20261103-21` 的电压基准约定）。
- 结果电压一律**相对 `PE` 所在等势点**（`0 V`）；无 `PE` 直接报错，不存在"相对某个电源相"的隐式基准。
- 频率只影响相角（一期），不影响阻抗模值；阻抗由器件参数直接给（不含频率相关的感抗换算）。
- 相位**对外一律度，范围 `(-180, 180]`**；内部弧度。

## 9 收敛与失败处理

| 情况 | 处理 |
|---|---|
| LU 残差 > `N-07` | 视为病态 → `E_SINGULAR_MATRIX`，诊断带上残差与最大节点 |
| 主元过小（`N-08`） | 同上 |
| 开关迭代超限 | `E_OSCILLATION` ＋ 振荡器件列表 |
| 无参考点 / 多参考点 | `E_NO_REFERENCE` / `E_MULTI_REFERENCE`（§4） |
| 短路 | `E_SHORT_CIRCUIT`（§7） |
| 过流但非短路 | **不算错误**：正常返回结果，附加 `W_OVERCURRENT` 诊断（`N-05`） |
| 孤岛分量 | 忽略，不出诊断（D-20261103-04） |

**一句话原则**：能给结果的给结果（过流、开路），给不出结果的必须给出可定位的错误码；**不存在"算了个大概然后静默返回"的路径**。

## 10 二期瞬时值预留（不实现）

- 一期所有结构体字段语义冻结；二期新增**独立结构体**（`PcxInstantaneousSample`）与独立导出函数，`ABI_VERSION` 常量单独导出（D-20261103-15）。
- 二期要加的东西（缺相、波形、相位差观察）需要时间步进；届时**应用侧时钟契约不变**，仍是"一次调用一个时刻"，只是该时刻可带瞬时采样序列。
- 本节只作接口约定，本期不写任何瞬时值代码；遇到有人想"先埋个 field 占位"的，一律拒绝 —— 占位字段会污染结构体布局与版本语义。
