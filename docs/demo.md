## 1 为什么选 C3，以及本期边界

C3（两地控制 / 双开双控）一次覆盖演示页必须证明的全部三件事：**① 自锁回路**（触点反馈，验证开关迭代）② **并联启动 ＋ 串联停止**（验证等势点合并与多支路）③ **接地参考**（验证 `E_NO_REFERENCE`）。

**本期边界**：只此一个案例、只此一张固定电路图。不做案例切换、不做三维、不做拖拽器件。

**明确不做**：C9 反接制动与 `KS`、假转速模型、`rpm` 控件。原因：C3 里没有 `KS`，而 `M` 是恒定阻抗不读 `rpm`（`D-20261103-06`），转速输入在本期**没有任何消费者**。它随二期 C9 案例一起做（`roadmap.md` §6）。

**库的调用模式**：演示页一律以 `STRICT_REFERENCE` **清零**（宽松模式）调用 —— 因为编辑中间态（导线被全部删光、只接了一半）必然没有完整参考点，而本页要求**每个接点在任何状态下都有正确数据**。正式网表（`fixtures/` 回归、Unity 样例）仍走严格模式，口径见 `solver.md` §4 与 `D-20261103-25`。

## 5 显示分层

65 个接点如果都在画布上堆文字必然糊成一团，所以分两层：

### 5.1 画布上

只显示**接点电压**（10 px，`220.0V` 形式）；电流不画在画布上。

- `flags.HAS_V = false` → 不显示。
- 数值为 `0` → 显示 `0V`（灰色），不隐藏 —— "这里有接点且它是 0 V"本身就是信息。

### 5.2 电流去哪了

进 §5.3 的接点表面板。这样既满足"每个接点都有值"，又不牺牲可读性。

### 5.3 接点表面板（右侧 `380 × 760`）

| 列 | 内容 |
|---|---|
| 位号 | `KM1` |
| 接点 | `13` |
| `V` | `219.4`（1 位小数） |
| `I` | `26.35 mA`（见 §6 的格式规则）；`HAS_I = false` 显示 `—` |
| 状态 | 触点闭合 / 断开（仅开关型器件） |

- 按器件分组，行高 18 px，可滚动。
- 面板顶部固定一行摘要：`C3 两地控制 ｜ 器件 15 ｜ 接点 65 ｜ 导线 30`。

### 5.4 悬停数据（必做，且必须永远有数）

**鼠标移入任意一个接点，必须弹出该接点的完整数据浮层；不管它通电与否、是否接成通路、是否属于任何一个有效回路。**

| 浮层字段 | 内容 | 空数据时 |
|---|---|---|
| 标题 | `位号 · 接点名`，副标题 `全局接点 #id` | 恒有 |
| 电压 | `V_rms` ＋ `∠V_phase_deg` | 显示 `0.0 V`（`FLOATING` 时补小字"未接入"） |
| 电流 | `I_rms` ＋ `∠I_phase_deg` | `HAS_I = 0` 显示 `—（该接点无内部支路）`；`FLOATING` 显示 `0.00 µA` |
| 等势点 | 合并后的等势点编号 ＋ 该点接点数 | 恒有（孤立接点也自成一点） |
| 连通分量 | 编号 ＋ 类型（`有源` / `无源孤立` / `单接点`） | 恒有 |
| 导通状态 | `通电` / `未通电` / `未接入` | 恒有 |
| 触点状态 | 该接点所在触点的 `闭合` / `断开`（仅开关型器件） | 非开关器件不显示该行 |

- **判据是"不能出现空浮层"**：65 个接点地毯式悬停一遍，任何一格显示"无数据"或空白都算不通过（D-10）。
- 触发延迟 120 ms，跟随光标偏移 `(+14, +14)`；贴到画布右/下边缘时翻转到左侧/上方。
- 浮层本身不拦截鼠标事件（`pointer-events: none` 或自绘），悬停不改变任何状态、不触发 `solve`。
- 浮层用 DOM 绝对定位的 `div`（不画在 canvas 上），避免与重绘互相干扰。

## 7 交互状态机

```
IDLE ──点接点A──► PICK_A(记下 first)
PICK_A ──点接点B(≠A)──► 校验通过 → 追加 wire → solve → 重绘 → IDLE
PICK_A ──点空白 / Esc──► IDLE
任意态 ──点已有导线(命中 ≤ 6 px)──► 删除该 wire → solve → 重绘
任意态 ──点开关型器件(SB/QS/SQ)──► 切换 state_bits → solve → 重绘
任意态 ──拖拽──► 只画预览虚线；松手才提交并 solve
```

**规则**：

1. **禁止重复导线**：已存在 `{a,b}`（无序）则忽略并提示"已有此导线"。
2. **禁止自环**：`a == b` 忽略。
3. **每次交互都必须重新 `solve`**，不做增量推断 —— 这是"删一根线，全图重算"的演示价值所在。
4. **导线允许全部删光**：删到 0 条也要 `solve` 成功（宽松模式，见 §1）。0 条导线时的期望结果是：`POWER` 分量以 `P1.N` 为隐含参考（`W_IMPLICIT_REFERENCE`），其余 61 个接点全为 `0.0 V` ＋ `FLOATING`，**不得报 error、不得不出数**。
5. **`清空全部导线`**：一次清空 `wires`（先弹一次确认，因为不可撤销）→ `solve` → 重绘；随后可从零逐条重接，接的过程中每一步都必须有数。
6. **`恢复初始网表`**：重新读 `fixtures/C3.json`，把 `devices` 的 `state_bits` 复位到初始态、`wires` 复位到 30 条 → `solve` → 重绘。
7. **不做 `Ctrl+Z`**：撤销带状态快照，本期不值得；用"恢复初始网表"兜底（记入二期）。
8. `solve` 返回**错误**时保留上一次成功结果用于绘制，同时诊断栏显示错误、画布顶部叠加红色横条写明原因（避免"图还在但数据是旧的"被误读）。**宽松模式正常情况下不应出现 error**，出现即为真 bug。
9. **瞬动元件用「按下 / 抬起」操作**：`SB` 与 `SQ` 在**鼠标按下**时动作（常开闭合、常闭断开），**鼠标抬起**时复位（含在画布外松开、窗口失焦）。这是自锁能演示的前提 —— 若按钮一按就锁住，`KM1` 的 `13-14` 自锁触点就没有存在意义。浮层提示「按住 X.Y（动作中）… 松开即复位」。
10. **保持型元件用「点击切换」**：`QS` 点一下翻转并保持（旋钮/刀开关的物理行为）。
11. **应用必须回传触点状态**：每次 `solve` 成功后，把 `KM` / `KA` / `KT` / `KS` / `FR` 的 `closed_bits` 写回该器件的 `state_bits`（`flags.bit0 = 0`）作为**下一轮的提示**。库是无状态的（`D-20261103-12`），不回传就会"松开按钮 → 自锁触点一起复位 → 立即失电"，自锁永远演示不出来。
12. 点击 `KM1` / `M1` / `FR1` / `FU1-5` / `PE1` 无操作（只有 `SB`/`QS`/`SQ` 可由人操作，`domain-model.md` §5）。
13. **悬停不改变任何状态**、不触发 `solve`（§5.4）。
