# verification — 黄金案例、基线与判据

读者：AI / 负责人
类型：设计
权威：10 类电路的验收断言、基线值、容差的唯一事实源
状态：2026-11-03 首版（基线为**自建值**，可随时按教材替换，D-20261103-10）
依赖：`domain-model.md` §4（器件参数）、`solver.md` §5（数值口径）、`api.md` §5（错误码）

## 1 三层验收

| 层 | 验什么 | 判据 | 谁来跑 |
|---|---|---|---|
| **结构** | 网表校验、错误码定位 | 每个错误码至少一个反例用例，且诊断能指到 `device_id` / `terminal_id` | `cargo test` |
| **数值** | 10 类电路的通断与电压电流 | §3 的断言，容差见 §2 | `cargo test` ＋ Unity 样例 ＋ 演示页 |
| **一致** | 双端等价 ＋ 确定性 | §4 字节级一致 | `scripts/compare` |

## 2 容差与判定

| 判据 | 值 | 说明 |
|---|---|---|
| 电流 / 电压相对容差 | **1%** | 教学以量级与相对关系为主，1% 足够严格又不脆弱 |
| 小于 `1 mA` 的量 | 按绝对 `0.01 mA` 判 | 避免小量相对误差放大（漏电 `0.38 µA` 这类） |
| 通断判定 | `I < 1 mA` 视为断开（`solver.md` `N-04`） | 与漏电 `0.38 µA` 差 2600 倍，无灰区 |
| 相位 | 绝对 `±0.5°` | 相序错误会差 120°，一眼可辨 |
| 确定性 | **字节级完全一致** | 不适用容差；`fixtures/` 回归比的就是字节 |

**基线可替换**：`domain-model.md` §4 的器件参数一改，本文件 §3 的数字就要重算。数字不是真理，接线关系才是；**断言优先写"相等/倍数/为零"这类关系，其次才写绝对值**。

## 3 10 类案例

每条格式：网表 → 操作序列 → 断言。所有案例的网表**必须含一个 `PE`**（D-20261103-21）。

### C1 点动（点控）

| 步骤 | 断言 |
|---|---|
| 初始（`SB` 松开） | `M` 各相 `I = 0`；`KM` 线圈 `I = 0`；`KM` 主触点断开 |
| 按下 `SB`（NO 闭合） | `M` 每相 `I = 5.02 A`（`∠-24.2°`）；`KM` 线圈 `I = 26.3 mA`，`flags.bit0 = 1`（吸合） |
| 松开 `SB` | 回到初始 |

### C2 单控自锁

| 步骤 | 断言 |
|---|---|
| 按启动 `SB2` 后松开 | `M` 每相仍 `5.02 A`（**自锁成立**，靠 `KM` 的 `13-14`） |
| 按停止 `SB1`（NC 断开） | `M` 全部 `0`，`KM` 释放 |
| 把 `FR` 的 `95-96` 置断开 | `M` 全部 `0`（过载保护链路有效） |

### C3 两地 / 多地点控制（**演示页即此电路**）

| 步骤 | 断言 |
|---|---|
| 地点 1 启动 → 松开 | `M` `5.02 A` |
| 地点 2 停止 | `M` `0` |
| 地点 2 启动 | `M` `5.02 A` |
| 两地停止同时按下 | `M` `0`，无错误码 |

### C4 正反转

| 步骤 | 断言 |
|---|---|
| 按正转 `SB` | `M` 每相 `5.02 A`，`U1` 相角 `0°`、`V1` `-120°`、`W1` `+120°` |
| 先断正转，再按反转 | `M` 每相 `5.02 A`，相序反转（`U1` 相角 `-120°`、`V1` `0°`、`W1` `+120°`） |
| **同时按下正/反** | 只有先吸合的那只线圈有电流（`26.3 mA`），另一只 `0`；**返回码 `PCX_OK`**，诊断里**没有** `E_SHORT_CIRCUIT`（电气互锁有效） |

### C5 降压启动（星三角）

| 步骤 | 断言 |
|---|---|
| `elapsed_ms < 3000`（星形） | `M` 相电流 = 线电流 = `5.02 A` |
| `elapsed_ms ≥ 3000`（切三角） | `M` 相电流 `8.66 A`、线电流 `15.01 A` |
| 倍数关系 | `15.01 / 5.02 ≈ 3`（误差 < 1%）—— 星三角的意义所在 |
| **故障注入**：强制两只接触器同时吸合 | `E_SHORT_CIRCUIT`，诊断给出短路的两个相与路径器件 id |

### C6 延迟启动

| 步骤 | 断言 |
|---|---|
| `KT` 线圈带电，`elapsed_ms = 2990` | `M` 全部 `0`；`KT` 的 `55-56` 断开 |
| `elapsed_ms = 3000` | `KT` 的 `55-56` 闭合，`67-68` 断开；`M` `5.02 A` |

### C7 变速（双速电机）

| 步骤 | 断言 |
|---|---|
| 低速绕组接通 | 该 `M` 每相 `5.02 A`，高速绕组 `0` |
| 切到高速绕组 | 高速 `M` 每相 `7.94 A`，低速 `0` |
| 两个 `M` 的 `shaft_group` | 相同且非 0（共轴声明正确） |

### C8 能耗制动（**只验接线状态，见 §5**）

| 步骤 | 断言 |
|---|---|
| 运行中断开三相接触器、投入 `R` | `M` 每相 `I = 0`，`R` 支路 `I = 0` |
| 接线状态 | `M` 三相已与 `POWER` 断开；`R` 已串入定子回路并形成闭合回路（用诊断 / 器件状态断言，不断言电流） |

### C9 反接制动

| 步骤 | 断言 |
|---|---|
| 反接两相，`rpm = 1300` | `M` 每相 `5.02 A`，相序与正转相反；`KS` 的 `13-14` **闭合** |
| `rpm` 降到 `90`（< `n_drop = 100`） | `KS` 的 `13-14` 释放 → 反接接触器失电 → `M` 全部 `0` |
| `rpm = 110`（滞环区间内） | 保持进入区间前的状态（**滞环生效**，不抖动） |

### C10 顺序控制

| 步骤 | 断言 |
|---|---|
| `M1` 启动，`SQ` 未到位 | `M1` `5.02 A`，`M2` `0` |
| `SQ` 动作（`3-4` 闭合） | `M2` `5.02 A` |
| `SQ` 复位 | `M2` `0`，`M1` 保持运行 |

## 4 确定性与双端等价

| 测试 | 做法 | 判据 |
|---|---|---|
| 重复求解 | 同一输入连跑 2 次 | 结果数组**字节相同** |
| 顺序无关 | 打乱 `wires` 数组顺序、打乱 `requested_*` 之外无影响；`devices` 顺序改变时同步改 `terminal_base` | 结果**语义等价**（同一接点 id 的 4 个 `f64` 字节相同） |
| 请求顺序 | `requested_terminals` 给不同顺序 | 返回顺序跟随请求，值不变 |
| 双端 | 同一 `fixtures/C*.json` 过 `cargo test` / Unity / wasm | 三处结果字节一致（`integration.md` §6） |

## 5 已知不覆盖（必须写清，避免被当成 bug）

| 不覆盖 | 原因 | 后果 |
|---|---|---|
| **C8 的制动电流** | 恒定阻抗模型无电动势，定子脱离电源后回路无源，电流必然为 0（D-20261103-06、D-20261103-18） | 该案例只断言接线状态；要算制动电流必须引入转速 / 转差率模型（D-20261103-18 的候选 B，属后续） |
| C9 的制动时间与制动电流峰值 | 同上，反接瞬间转子尚有转速，实际电流大于 `5.02 A` | 只断言稳态相电流与 `KS` 动作逻辑 |
| 转速 / 转矩 / 启动曲线 | 库不算转速，`rpm` 是应用输入 | 由应用侧假模型决定，不进本文件的基线 |
| `FU` 熔断 | 本期不建模（`domain-model.md` §2.3） | 短路只报诊断，不"烧断"器件 |
| FR 冷却 / I²t | 纯逻辑延时 | 过载消失即清零，不做热记忆 |

## 6 教材校准入口（D-20261103-10）

- 本文件所有绝对值为**自建基线**，来源 = `domain-model.md` §4 的器件参数表。
- 拿到教材具体数据后，只改 §4 参数表 ＋ 重跑回归，**不改本文件的断言结构**（关系类断言天然免疫参数变化）。
- 每个案例在 `fixtures/` 下的 JSON 里带 `baseline_source` 字段，写明该组数字来自"自建"还是某教材某表，便于将来追责与替换。
