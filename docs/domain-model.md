# domain-model — 元器件接点契约、网表结构与参数表

读者：AI / 负责人
类型：契约
权威：器件类型、接点编号、支路展开、教学典型值的唯一事实源
状态：2026-11-03 首版（15 类器件 ＋ 导线，接点编号全部采用器件手册编号）
依赖：`../DECISION.md`（D-04/D-05/D-06/D-18/D-20）、`solver.md`（数值口径）

## 1 网表三要素与 id 规则

| 要素 | 结构 | id 规则 |
|---|---|---|
| **器件** | `{kind: u8, id: u32, params: [f64; 8], terminal_base: u32}` | `id` 由应用给，**全表唯一**（重复即 `E_DUPLICATE_ID`） |
| **接点** | 器件的第 `i` 个接点 | 全局 id = `terminal_base + i`；`i` 严格按本文 §2 表内顺序（0 起） |
| **导线** | `{a: u32, b: u32}`，两端接点 id | 独立数组，**不是器件**；理想连接，参与等势合并 |

`terminal_base` 由应用计算：按器件数组顺序做**接点数前缀和**。库提供 `pcx_terminal_count(kind, params)` 供应用核对，避免算错。接点数随参数变化（如 `QS` 的极数、`KM` 的辅助触点组数）。

**接点总数上限**：一期 1024（够 10 类电路 30 倍余量），超限返回 `E_TERMINAL_LIMIT`。

## 2 器件接点表

顺序即接点序号（0 起）。`terminal_base + 序号` 即全局接点 id。

### 2.1 `POWER` 三相电源（4 接点）

| 序号 | 接点 | 含义 |
|---|---|---|
| 0 | `L1` | A 相 |
| 1 | `L2` | B 相 |
| 2 | `L3` | C 相 |
| 3 | `N` | 中性点 |

- 内部：3 条电压源支路 `L1-N`、`L2-N`、`L3-N`，幅值 = `v_line/√3`，相角 `0° / -120° / +120°`（正序），每支路串内阻 `r_src`。
- **一切计算的起点**：电压等级、频率、内阻全部由电源参数传入（D-20261103-12）。
- 与 `PE` 的关系：电源中性点**不自动接地**；要参考必须另放 `PE` 器件并用导线连到 `N`（否则 `E_NO_REFERENCE`，见 `solver.md` §4）。

### 2.2 `QS` 旋钮开关 / 隔离开关（极数决定）

| `poles` | 接点（按序） |
|---|---|
| 1 | `1`、`2` |
| 3 | `1`、`3`、`5`（进）、`2`、`4`、`6`（出） |

支路：每极 1 条（`1-2`、`3-4`、`5-6`）。状态由**应用**给（人工操作）。

### 2.3 `FU` 熔断器（2 接点）

`1`、`2`。支路 1 条。**本期不建模熔断**：恒为闭合（`r_contact`），短路只以诊断形式报出（`solver.md` §7）。

### 2.4 `KM` 交流接触器（12 基础 ＋ 可选 4）

| 序号 | 接点 | 含义 |
|---|---|---|
| 0-1 | `A1`、`A2` | 线圈 |
| 2-7 | `1`,`2`,`3`,`4`,`5`,`6` | 主触点（1-2 / 3-4 / 5-6） |
| 8-9 | `13`、`14` | 辅助常开 NO（第 1 组） |
| 10-11 | `21`、`22` | 辅助常闭 NC（第 1 组） |
| 12-13 | `43`、`44` | 辅助常开 NO（第 2 组，仅 `aux_no = 2` 时存在） |
| 14-15 | `31`、`32` | 辅助常闭 NC（第 2 组，仅 `aux_nc = 2` 时存在） |

支路：线圈 1 条（`A1-A2`，阻抗 `Z_coil`）＋ 每条触点 1 条（闭合 `r_contact` / 断开 `r_open`）。
状态：**库自解** —— 线圈电流 ≥ `pick_current` 吸合、≤ `drop_current` 释放（滞环，`solver.md` §6）。

### 2.5 `KA` 中间继电器（6 ＋ 可选 4）

| 序号 | 接点 |
|---|---|
| 0-1 | `A1`、`A2` |
| 2-3 | `13`、`14`（NO 第 1 组） |
| 4-5 | `21`、`22`（NC 第 1 组） |
| 6-7 | `43`、`44`（NO 第 2 组，`aux_no = 2`） |
| 8-9 | `31`、`32`（NC 第 2 组，`aux_nc = 2`） |

无主触点。状态来源同 `KM`。

### 2.6 `KT` 时间继电器（6 接点）

| 序号 | 接点 | 含义 |
|---|---|---|
| 0-1 | `A1`、`A2` | 线圈 |
| 2-3 | `55`、`56` | **延时闭合**常开 |
| 4-5 | `67`、`68` | **延时断开**常闭 |

> 延时触点用 IEC 常见编号（55-56 / 67-68）。若教材用别的编号，只需在绑定层改显示标签，**不影响计算**。

状态：库判断 —— 线圈带电持续 `delay_ms` 后 `55-56` 闭合、`67-68` 断开；`delay_ms` 的累积量（`elapsed_ms`）由**应用**传入（D-20261103-12）。

### 2.7 `KS` 速度继电器（4 接点，本期新增）

| 序号 | 接点 | 含义 |
|---|---|---|
| 0-1 | `13`、`14` | 正转动作常开 |
| 2-3 | `23`、`24` | 反转动作常开 |

- 无线圈；机械上与受控电机共轴（`shaft_group` 标签配对）。
- 状态：库判断 —— 应用传入的 `rpm` 在 `(n_drop, n_pick)` 区间内保持上一状态（滞环）；`rpm ≥ n_pick` 闭合，`rpm ≤ n_drop` 释放；反转为对称的负转速区间。
- **转速由应用提供，库不计算转速**（D-20261103-18）。见 `../TODO.md` P-22。

### 2.8 `FR` 热继电器（10 接点）

| 序号 | 接点 | 含义 |
|---|---|---|
| 0-5 | `1`,`2`,`3`,`4`,`5`,`6` | 三相热元件（1-2 / 3-4 / 5-6） |
| 6-7 | `95`、`96` | 控制回路常闭（过载跳开） |
| 8-9 | `97`、`98` | 控制回路常开（过载闭合，报警用） |

状态：库判断 —— 任一相主回路电流 > `set_current` 且累加 `elapsed_ms ≥ delay_ms` 后 `95-96` 断开、`97-98` 闭合。累加量由应用传入。

### 2.9 `SB` 按钮（4 接点）

| 序号 | 接点 | 含义 |
|---|---|---|
| 0-1 | `1`、`2` | 常闭 NC |
| 2-3 | `3`、`4` | 常开 NO |

`type ∈ {NC, NO, BOTH}`；`BOTH` 时两组成机械联动（按下：NC 先断、NO 后合，本期内视为同时）。状态由应用给。

### 2.10 `SQ` 行程开关（4 接点，本期新增）

接点与 `SB` 完全一致（`1-2` NC、`3-4` NO）。状态由**应用**给（机械位置到位 / 复位）。

### 2.11 `M` 三相异步电动机（6 接点）

| 序号 | 接点 |
|---|---|
| 0-2 | `U1`、`V1`、`W1` |
| 3-5 | `U2`、`V2`、`W2` |

内部：**3 条阻抗支路** `U1-U2`、`V1-V2`、`W1-W2`，每相 `R_phase + jX_phase`。

- **星 / 三角由外部接线决定**，器件本身不区分接法：`U2/V2/W2` 短接（导线连一起）= 星形；`U2-V1`、`V2-W1`、`W2-U1` 相连 = 三角形。这是让"星三角启动"能被纯接线表达的关键设计。
- **双速电机不新增器件**：低速绕组与高速绕组各用一个 `M` 器件，靠 `shaft_group` 标签声明共轴（D-20261103-20）。
- 恒定阻抗模型（D-20261103-06）：不输出转速 / 转矩，不含反电动势。

### 2.12 `R` 电阻（2 接点）

`1`、`2`，单支路 `resistance`。**制动电阻直接复用本器件**，不单列（D-20261103-20）。

### 2.13 `EL` 指示灯（2 接点）

`1`、`2`，单支路。参数 `rated_voltage` ＋ `power`，等效 `R = U²/P`（纯阻性，无 X）。

### 2.14 `TB` 接线端子排（`n` 接点）

接点按 `0..n-1` 顺序编号，参数 `n ∈ [2, 8]`。**内部两两等势**（不是支路，是等势合并关系），用于中转与分支。无内部支路 → 该接点的电流结果标记 `HAS_I = false`。

### 2.15 `PE` 接地（1 接点）

唯一接点 `PE`。该接点所在等势点被定义为 **`0 V` 参考点**。全表必须**有且仅有一个** `PE`（`solver.md` §4）。

## 3 导线与等势合并

- `wires` 是独立数组（非器件），每条 `{a, b}`。
- 合并范围：`wires` ＋ `TB` 内部 ＋ 同一接点的重复声明。
- **不合并**：闭合触点。触点有 `r_contact = 1e-3 Ω`，必须参与求解 —— "导线理想连接"与"触点有接触电阻"是两个不同的物理假设，不能混（D-20261103-04）。

## 4 教学典型值表（可替换，D-20261103-10）

**这张表是全工程的参数基线**；`solver.md` §5 的常量表管数值口径（接触电阻、漏电、阈值、容差），本表管器件参数。改本表的值只需重跑 `fixtures/` 回归，不改架构。

| 参数 | 值 | 说明 / 依据 |
|---|---|---|
| `POWER.v_line` | `380 V` | 三相线电压（常考点） |
| `POWER.freq` | `50 Hz` | 常考点 |
| `POWER.r_src` | `1e-3 Ω` | 电源内阻，避免理想电压源无穷大短路电流 |
| `QS` / `FU` / 触点 `r_contact` | `1e-3 Ω` | 真实接触电阻 mΩ 级 |
| 任意断开状态 `r_open` | `1e9 Ω` | 见 `solver.md` §5 常量表 |
| `KM` / `KA` 线圈 `Z_coil` | `12000 + j8000 Ω` | 380 V 线圈，`\|Z\| = 14422 Ω` → 线圈电流 `26.3 mA` |
| `KM` / `KA` `pick_current` | `20 mA` | 略低于额定线圈电流 |
| `KM` / `KA` `drop_current` | `12 mA` | 约为吸合点的 0.6 倍，构成滞环 |
| `KT` 线圈 `Z_coil` | `15000 + j10000 Ω` | `\|Z\| = 18028 Ω` → `21.1 mA` |
| `KT.delay_ms` | `3000 ms` | 星三角切换整定 |
| `KS.n_pick` / `n_drop` | `120 / 100 rpm` | 反接制动释放转速 |
| `FR.set_current` | `6 A` | 略高于电机额定 5.02 A |
| `FR.delay_ms` | `5000 ms` | 教学演示需秒级可见跳闸 |
| `FR` 热元件电阻 | `1e-3 Ω` | 串联导体 |
| `M` 低速绕组 | `R = 40 Ω, X = 18 Ω`（每相） | `\|Z\| = 43.86 Ω` → 星形相电流 `5.02 A` |
| `M` 高速绕组 | `R = 25 Ω, X = 12 Ω`（每相） | `\|Z\| = 27.73 Ω` → 星形相电流 `7.94 A` |
| `R` 制动电阻 | `30 Ω` | 能耗制动投入 |
| `EL` | `220 V / 2 W` → `R = 24200 Ω` | 指示灯电流 `9.09 mA` |

由上表直接推出的三个**可断言基线**（`verification.md` 引用）：

| 工况 | 计算 | 基线 |
|---|---|---|
| 电机星形运行 | `220 / 43.86` | 相电流 = 线电流 = **5.02 A** |
| 电机三角形运行 | `380 / 43.86`，线 = `√3 ×` 相 | 相电流 **8.66 A**，线电流 **15.01 A** |
| 星三角效果 | `15.01 / 5.02` | 启动电流约为运行电流的 **1/3**（星形启动的意义） |

## 5 谁决定触点状态（求解契约）

触点状态只有两个来源，**不存在第三个**：

| 来源 | 器件 | 说明 |
|---|---|---|
| **应用给定**（人在操作 / 机械位置） | `QS`、`SB`、`SQ` | 随输入传入，库不推断 |
| **库自解**（电气或状态判断） | `KM`、`KA`（线圈电流 ＋ 滞环）、`KT`（`elapsed_ms` ≥ `delay_ms`）、`FR`（过载 ＋ `elapsed_ms`）、`KS`（`rpm` 与滞环阈值） | 库只做判断，**累积量由应用提供** |
| **恒定** | `FU`（恒闭合） | 不建模熔断 |

应用要交回的跨时刻量（每次 `solve` 的输入）：`KT.elapsed_ms`、`FR.elapsed_ms`、`KS` 所在 `shaft_group` 的 `rpm`。线圈 / 触点状态由库自解，但应用可带上一次的 `closed` 位作为**收敛提示**（用于滞环延续，不传也能算）。

## 6 校验规则（输入侧，全部返回错误码）

| 规则 | 错误码 |
|---|---|
| 器件 `id` 重复 | `E_DUPLICATE_ID` |
| `terminal_base` 与 `pcx_terminal_count` 不一致 | `E_TERMINAL_RANGE` |
| `kind` 不在 15 类内 | `E_UNKNOWN_KIND` |
| `aux_no` / `aux_nc` / `poles` / `n` 越界 | `E_PARAM_RANGE` |
| 导线端点接点 id 越界 | `E_TERMINAL_RANGE` |
| 电阻 ≤ 0、`X < 0`、`set_current ≤ 0` | `E_PARAM_RANGE` |
| 接点总数 > 1024 | `E_TERMINAL_LIMIT` |
| 无 `PE` 或多于一个 `PE` | `E_NO_REFERENCE` / `E_MULTI_REFERENCE` |

错误码全文见 `api.md` §5。
