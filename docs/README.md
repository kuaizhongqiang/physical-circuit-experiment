## 2 已定死、改文档时不得偏离的口径

- **语言与双端**：Rust 单源码，`cdylib` → Windows DLL 供 Unity，`wasm32` → Web（D-01、D-08）。
- **调用形态**：无状态单次求解，起点是电源参数；应用自持时钟与器件状态；无会话对象、无 `advance()`、无事件时刻输出（D-02、D-12）。
- **数值**：全链路 `f64`，禁 `f32`；无 0 Ω 与 ∞ Ω；常量表在 `solver.md` §5（D-04、D-13）。
- **拓扑语义**：导线为理想连接（等势合并、不计长度），**触点有 `1e-3 Ω` 接触电阻不参与合并**，端子是可求解节点，孤岛忽略，接地是特殊元器件（D-04）。
- **参考点**：每个连通分量必须恰含一个 `PE`，缺失 / 重复直接报错；电压一律相对 `PE`（D-21）。
- **短路**：拓扑预检（导体类通路），不靠电流阈值；每轮迭代都判（D-22）。
- **范围**：10 类电路（11 → 10，"双开双控"取拖动义并与"多地点控制"合并），15 类器件（D-09、D-19、D-20）。
- **输出**：每接点 4 个 `f64`（`V_rms` / `V_phase_deg` / `I_rms` / `I_phase_deg`），不导出 Re/Im；二期瞬时值另立结构体并存（D-15）。
- **ABI**：调用方分配缓冲、库只写、无 `free`、双阶段查询、`u32` 错误码 ＋ 上下文结构体、文案不进库（D-17）。
- **演示页**：单文件 HTML ＋ Canvas 2D；rect ＋ 文字 ＋ 接点圆点 ＋ 直线；交互后同步重算全量重绘（D-16）。

## 3 写作约定

- 功能 / 设计文档第 3 行起固定五行头：`读者 / 类型 / 权威 / 状态 / 依赖`（索引与机器可读文件除外）。
- 一份文档只解一件事；同一口径只写一处，别处**引用不复述**。
- **数值只有一个家**：数值口径在 `solver.md` §5（`N-01…N-12`），器件参数在 `domain-model.md` §4；代码 `core::consts` 与 `N-*` 逐项编号对应，`domain-model.md` §4 的表只被 `verification.md` 引用、不复写。
- 表格优先于散文：接点表、参数表、错误码表、案例表一律用表。
- 已拍板口径引用 `DECISION.md` 编号，不抄原文；文档与代码冲突以代码为准，同批补齐文档。
- 跨文档引用的编号（`C1…C10`、`N-01…N-12`、错误码、器件 `kind`）**全工程统一**，任何一处改名都要全量同步。
