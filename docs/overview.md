## 1 工程定位

做一个**独立的电路计算内核库**，替原有 Unity 工程里的 C# 拓扑计算：输入一张电路网表（元器件 ＋ 接线 ＋ 电源参数），输出每个接点的电压 / 电流与每台器件的工作状态。

为什么值得单独做一个库：原工程"容易出错"的根因不在语言（见 `solver.md` §1 与 D-20261103-11），而在建模与数值口径；把内核抽出来，才能做到**一份源码同时供 Unity 与 Web，且两端结果逐字节一致**（D-20261103-01）。

## 2 两个交付物

| 端 | 四件套 | 说明 |
|---|---|---|
| Unity | Windows DLL ＋ C# 接口 ＋ C#（Mono）样例 ＋ 接入文档 | 只覆盖 Unity Editor（Windows），不做移动端 / WebGL（D-20261103-08） |
| Web | wasm ＋ JS/TS 接口 ＋ 样例 ＋ **演示页** | 演示页单文件 HTML ＋ Canvas 2D，双开双控电路，可增删线（D-20261103-16） |

**不发布 npm**，产物直接拷贝即用（D-20261103-08）。

## 3 本期电路范围（10 类）

原提 7 类 ＋ 我方补 4 类，其中"双开双控"与"多地点控制"取**拖动义**后为同一类（两地 = 两处；三处以上为多地点），合并为一类，故 **11 → 10**（D-20261103-19）。

| # | 电路 | 核心器件 | 主要动作 | 验收断言要点 |
|---|---|---|---|---|
| C1 | **点动（点控）** | SB(NO)、KM、M | 按住转、松开停 | 按下时电机线电流 = 额定、松开为 0；KM 线圈电流达吸合点 |
| C2 | **单控自锁** | SB 启/停、KM 自锁辅助 NO、FR 95-96、M | 松手仍运行 | 松开启动按钮后电机仍转（自锁成立）；按停止后全断；FR 动作后自锁解除 |
| C3 | **两地 / 多地点控制（双开双控）** | 两组 SB 启停、KM 自锁、M | 任一地点可启停 | 任一启动作业、任一停止停机；两组按钮同时按下不冲突。**演示页即此电路** |
| C4 | **正反转** | KM1、KM2、电气互锁（对方 NC 串入自己线圈）、M | 换相序 | 同时按下只有先动作者吸合、另一只不吸合；换相后相序改变；无短路诊断 |
| C5 | **降压启动（星三角）** | KM 主/星/三角、KT、M（6 接点） | 先 Y 后 Δ | 启动期相电流 = 运行期 1/3；切换时刻 = KT 整定值；切换瞬间不产生短路 |
| C6 | **延迟启动** | KT、KM、M | 延时后自动启动 | 延时到点前电机电流为 0，到点后达额定 |
| C7 | **变速（双速电机）** | M 低速绕组、M 高速绕组、切换 KM | 两套绕组切换 | 低速/高速两套参数各自成立，切换后电流按新绕组计算 |
| C8 | **能耗制动** | 断电接触器、制动电阻 R、M | 定子脱离三相后经 R 闭合成回路 | 制动瞬间定子回路有电流且方向由 R 决定；制动电流按 `M ＋ R` 串联阻抗算 |
| C9 | **反接制动** | 反接 KM、**KS 速度继电器**、M | 两相调换制动 | 制动期间 KS 触点闭合；转速降到释放转速后 KS 触点断开、电路复位 |
| C10 | **顺序控制** | **SQ 行程开关** 或 KT、两台 M | 先 A 后 B | 第一台未到位时第二台无电；SQ 动作后第二台启动 |

**"只算电气量"的边界**（D-20261103-18）：C7 / C8 / C9 三类只输出通断与电压电流，**不输出转速、转矩、制动时间**。C9 的 KS 需要转速，转速由**应用**提供（见 `solver.md` §6 与 P-22）。

## 5 网表的三个概念

- **器件**：有类型、有接点、有参数。每个接点有全局唯一的**接点 id**。
- **接点**：可求解节点。结果以接点为粒度给出（电压、电流），这是原始需求"每个接点需要有的数据"的落点。
- **导线**：`{a, b}` 两个接点，理想连接。求解前把导线（以及端子排内部）连起来的接点**合并成等势点**，矩阵建在等势点上。

电源参数（电压等级、频率、相数、内阻）随输入全量传入，是"一切的起点"（D-20261103-12）。

## 6 不做清单（本期明确不做，后续可能加）

| 不做的事 | 原因 |
|---|---|
| PLC 与梯形图 | 范围外 |
| 照明与单相插座回路 | "双开双控"已取拖动义（D-20261103-19），本期无单相 220 V 回路域 |
| 变压器、变频器、整流 | 器件模型不在本期清单 |
| 短路电流校验、选择性配合、热稳定校验、线径选型 | 属设计计算，不属接线计算 |
| 三相不平衡度 / 谐波分析 | 一期为相量稳态，不含频谱 |
| 转速、转矩、制动时间、启动过程的动态曲线 | D-20261103-18 只算电气量 |
| 评分 / 判题 / 考试逻辑 | 本期只做计算 |
| 移动端、Unity WebGL、macOS/Linux | D-20261103-08 只覆盖 Windows Editor |
| npm 包发布 | D-20261103-08 |
| 三维演示、自由拖拽的实物接线 | D-20261103-16 本期只做二维 Canvas |

## 7 术语表

| 术语 | 含义 |
|---|---|
| **等势点** | 由导线 / 端子排连接起来的一组接点，电位相同，合并成一个矩阵节点 |
| **支路** | 器件内部的一条导电路径（如电机的一相绕组、接触器的一组触点） |
| **连通分量** | 通过导线连在一起的一坨接点；孤岛分量直接忽略（D-20261103-04） |
| **参考点** | 接地器件所在的等势点，电位定义为 `0 V`；全工程只允许一个（D-20261103-21） |
| **相量** | 一期口径：用 RMS 幅值 ＋ 相角（度）表示正弦量（D-20261103-03） |
| **吸合点 / 释放点** | 接触器 / 继电器线圈电流的吸合阈值与释放阈值，两者构成滞环 |
| **状态向量** | 全部开关型器件的触点通断取值的组合；开关迭代即求不动点 |
| **导体类器件** | 导线、QS、FU、FR 热元件、各类闭合触点 —— 用于短路拓扑判定 |
| **负载类器件** | M、R、EL、线圈 —— 有这些在路径里就不算短路 |
